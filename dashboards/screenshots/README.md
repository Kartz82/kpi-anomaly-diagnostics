# Screenshot Checklist

Capture the following dashboard screenshots after launching the app:

```bash
streamlit run dashboards/streamlit_app.py
```

Recommended image size:
- Width: 1440 px
- Height: 900 px

Required files:

- `executive_overview.png`
- `kpi_health.png`
- `anomaly_timeline.png`
- `root_cause_explorer.png`
- `data_quality.png`
- `incident_center.png`

Manual checklist:

- Verify the Executive Overview shows KPI count, health score, anomalies, incidents, and best detector.
- Verify KPI Health shows the KPI time series and status distribution.
- Verify Anomaly Timeline shows anomaly counts and evaluation metrics.
- Verify Root Cause Explorer shows contribution ranking and RCA statements.
- Verify Data Quality shows health score and validation checks.
- Verify Incident Center shows incident history and incident detail fields.

These screenshots are not generated automatically by the repo. Capture them
locally when preparing the final portfolio.
